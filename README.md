# Sudonea

Sudoku für Android (Kotlin, Jetpack Compose). Rätsel entstehen auf dem Gerät mit eindeutiger Lösung in drei Stufen, Tipps erklären die nächste Technik, dazu Tagesrätsel mit Serie, Notizen, Rückgängig und Statistik. Werbung: ein Banner (AdMob, mit Einwilligungsabfrage).

Eine Idee von autoknigge.de. Paketname: `de.autoknigge.sudonea`.

Build: GitHub Actions (APK + AAB). Signierung über die Secrets `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
